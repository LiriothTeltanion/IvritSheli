## Why this candidate exists

The one-item semantic scene used a single raised finger. In a small README card
that pose looked like a middle finger, so the illustration was culturally
ambiguous even though the code was counting correctly. A green component suite
could prove the SVG rendered; it could not prove how a human would interpret
the final composition.

The candidate replaces the pose with **one coffee cup**, the numeral `1`, and
one count dot. `כוס` is feminine, so the object agrees with the reviewed Hebrew
counting form `אחת`. The ambient Today spotlight now begins with `שתיים` and
two coffee cups, giving public proof a different word and an unmistakable
quantity scene.

## Errors turned into durable rules

| Error | Root cause | Durable response |
|---|---|---|
| A counting scene looked offensive in README captures | The isolated raised-finger silhouette was culturally ambiguous at card size | Prefer a countable everyday object, numeral, and count dot; inspect the real served composition at mobile and desktop sizes |
| Regenerating the public dictionary also changed an unrelated reviewed alt | The generator did not encode the already-reviewed exceptional wording | Keep the exception in the canonical source and compare all 240 source/public descriptions exactly |
| Playwright looked silent while every test waited for the shell | Cached HTML referenced a Vite bundle removed by a later build | Build before backend start; verify listener provenance and every HTML entry asset; inspect one trace before any rerun |
