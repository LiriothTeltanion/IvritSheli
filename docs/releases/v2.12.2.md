# Ivrit Sheli 2.12.2 — Visual Harmony & Resilience

Ivrit Sheli 2.12.2 publishes the reviewed source behind the Living Hebrew
Nocturne experience. It is a GitHub source release, not a hosted deployment.

## ✨ Highlights

- Trilingual English, Spanish, and Hebrew interface with native RTL/LTR layout,
  persistent dark/light themes, reduced-motion support, responsive navigation,
  and accessible keyboard and screen-reader semantics.
- Three learner experiences—Guided, Explorer, and Experienced—over one shared
  learning history, plus Alphabet Studio for 22 base letters and 5 positional
  final forms.
- A reviewed 240-concept starter catalog with 240 exact, deterministic semantic
  scenes rendered locally at thumbnail, card, and hero sizes.
- Responsive Israel journey art, a unified Nocturne wordmark and app icon,
  fifteen selectable vector avatars, and privacy-reviewed README evidence.
- Local SQLite mode without an account, plus an optional PostgreSQL 17 path
  protected by a restricted runtime role and forced row-level security.
- Deterministic coaching and optional, separately configured self-hosted speech
  and Web Push capabilities; the core learning path requires neither paid AI
  nor cloud audio.

## ⚠️ Boundaries

- No durable hosted demo is currently verified. The former Railway service is
  offline, and temporary tunnel sessions are not product URLs.
- This release does not deploy the application or change a database, OAuth
  client, external provider, Devpost entry, or production configuration.
- Generated contact-sheet inspection, human five-second recognition,
  Hebrew-content acceptance, the pilot with Kevin's mother, isolated HTTPS
  staging, two-real-account continuity and isolation, and backup/restore remain
  open.
- The Playwright suite uses deterministic API fixtures. It proves browser
  behavior on the FastAPI-served bundle, not provider or hosted persistence.
