# Ivrit Sheli 2.13.0 — Living Painted Scenes

Ivrit Sheli 2.13.0 publishes the source behind the painted, animated word scenes. It is a GitHub source release.
A free Render service runs the same 2.13.0 product as staging for a private pilot; that service is not production.

## ✨ Highlights

- Painted gouache settings of everyday Israel, each with a dark-theme version, behind 157 of the 165 paintable
  scenes. The eight left drawn are maps, arrows and notice cards, where the diagram is what teaches.
- One family of animated adults, with faces, sleeves and hands, runs through all 240 exact semantic scenes. Each
  scene replays on a tap and wakes once when it scrolls into view; thumbnails and reduced motion stay still.
- Today leads with a painted place: when the daily rotation opens on a counting diagram or a notice card, the first
  painted scene of the same six takes the hero card.
- One language picker for every header. On phones a 44 px button with the current code opens the three-language
  choice; it mirrors in Hebrew and its accessible name starts with the visible code (WCAG 2.5.3).
- The learner's theme and language are saved with their profile, and Today greets them by the name they chose.
- The light theme's Today metric cards follow the theme tokens, and the phone help button keeps its `?` badge.

## ⚠️ Boundaries

- Not run: PostgreSQL integration with live credentials, human five-second recognition, a native-speaker review of
  the new Hebrew strings and the pilot with the first real learner. That pilot is planned for 2026-11-03 or
  2026-11-04; what it finds goes into 2.13.1.
- This release does not redeploy the application or change a database, OAuth client, external provider, Devpost
  entry or production configuration.
- The Playwright suite uses deterministic API fixtures. It proves browser behaviour on the FastAPI-served bundle,
  not provider or hosted persistence.
- The painted settings are generated static images; their provenance and hashes are in
  `frontend/public/art-direction/living-scenes/painted/manifest.json`. Characters, teaching objects and all motion
  remain deterministic SVG.
