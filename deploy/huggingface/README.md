# Ivrit Sheli

A trilingual (English / Español / עברית) Hebrew-learning progressive web app,
built for adult beginners. 240 hand-drawn deterministic scenes, listening and
speech practice, and an interface that works offline.

This Space runs the production container from
[LiriothTeltanion/IvritSheli](https://github.com/LiriothTeltanion/IvritSheli).

**No tracking, and not by promise:** the bundle contains no analytics script and
the application's own Content-Security-Policy is `connect-src 'self'`, so the
browser is forbidden from reaching any other host.
