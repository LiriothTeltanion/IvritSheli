# Ivrit Sheli v2.12.2 — Visual Harmony & Resilience

Published as a GitHub source release on 2026-08-27.

## What this proves

- 240 reviewed learning concepts map to 240 exact local semantic scenes.
- English, Spanish and Hebrew interfaces support LTR/RTL, persistent themes,
  keyboard use, reduced motion and responsive navigation.
- The local release gate records 858 frontend tests, 363 backend tests, four
  capture contracts and 35 served-path Playwright passes.
- Five current README images were reviewed for privacy, full-size rendering and
  grayscale readability.

## What this does not prove

- There is no verified durable hosted demo; the former Railway service is
  offline.
- This release does not deploy the app or change a database, OAuth client,
  provider, Devpost entry or production configuration.
- Human five-second recognition, Hebrew-content acceptance, the pilot with
  Kevin's mother, isolated HTTPS staging, two-real-account isolation and
  backup/restore remain open.

The canonical evidence ledger is `TEST_REPORT.md`; release notes live at
`docs/releases/v2.12.2.md` in the repository.
